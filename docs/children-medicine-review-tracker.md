### 01/01｜粉薬の飲ませ方：PMDA Q8
原典：[PMDA「赤ちゃんに医師から処方された粉薬を飲ませるよい方法」](https://www.pmda.go.jp/safety/consultation-for-patients/on-drugs/qa/0008.html)

| 確認した主張 | 判定 | 記録 |
|---|---|---|
| 服用直前に少量の水・湯冷ましで混ぜる | 一致 | PMDA回答本文に記載あり |
| 少量の水でペーストにし、頬の内側へつける | 一致（製剤ごとの確認が必要） | PMDA解説①に記載あり |
| ミルク・おかゆなど主食に混ぜない | 一致 | PMDA「飲食物に混ぜて飲ませる時の注意点」に明記 |
| 熱い食品・酸性度の強い飲食物に注意、混ぜたまま放置しない | 記事への追記候補 | 当該記事は食品混合を別記事へ案内。別記事との整合性も点検対象 |
| 1歳未満でははちみつに混ぜない | 記事への追記候補 | 原典に明記あり。個別の食品混合記事も要確認 |
| 上体を起こす、むせへの注意、量が不明な場合の対応 | 追加確認 | PMDA Q8のみでは個々の主張すべてを照合できない |

### 05/01｜薬の誤飲予防：消費者庁
原典：[消費者庁「Vol.639 医薬品の誤飲事故」](https://www.caa.go.jp/policies/policy/consumer_safety/child/project_001/mail/20231020/)／[2015年調査報告書](https://www.caa.go.jp/policies/council/csic/report/report_007/)

| 確認した主張 | 判定 | 記録 |
|---|---|---|
| 1歳児が約1mの引き出しから風邪薬を取り出し入院 | 一致 | Vol.639の事例に明記 |
| 2歳児の向精神薬、3歳児の祖父の薬、7歳児の喘息薬の事例 | 一致（記事は要約） | Vol.639で人数・経緯・転帰の骨子を確認 |
| 高い場所だけに頼らず、見えない・触れない保管や施錠を検討 | 一致 | Vol.639の注意喚起、2015年調査報告書で裏付け |
| 誤飲疑いは症状がなくても相談、意識・呼吸の異常は救急車 | 一致 | Vol.639に明記 |
| 家庭での具体的な収納実装と個別医薬品の危険性 | 追加確認 | 実際の薬剤別評価は別途必要 |
