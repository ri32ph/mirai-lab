運営者から今回の6記事について「確認済み。検証後に公開する」と回答を受領。医学的な最終確認の実施者を自動検証で代替したものではない。

ZIPの適用スクリプトは実行せず、既存構成に合わせて組み込んだ。既存症状記事の本文は変更せず関連記事を追加。トップは症状、健診、体の数字の順。コンテンツ一覧、探すページ、共通検索、健診ガイドからも接続。

計算はブラウザ内のみ。入力値の保存・送信はしない。BMI、体脂肪量・除脂肪量、体重変化率は診断や受診判定を行わない。ゼロ、負数、非有限値、桁あふれ、体脂肪率100%以上を拒否する。
