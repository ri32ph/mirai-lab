# 参考文献の選び方

1. 服用条件、禁忌、必要な注意は現行の国内電子添文・患者向ガイドを確認する。
2. 相互作用の評価・管理の考え方は、適用範囲を確認した学会ガイド・公的ガイドラインを使う。
3. 食品との実際の影響は、ヒト試験・症例報告などの原著を確認し、研究条件と限界を明示する。薬物動態の変化と臨床上の有害事象を同じ結果として扱わない。
4. HFNetなど引用文献をたどれる解説は、対象薬・原著への橋渡しに利用する。機関名だけを信頼性の理由にしない。
5. 城西大学などのデータベースは個別レコードと出典を確認してから、特定の主張の根拠として採用する。トップページを読んだだけで個別の相互作用を確認済みとしない。
6. 出典のない一般向け表は、単独で医学的な説明を裏づける参考文献として使わない。説明の参考に使う場合も、根拠は別途照合する。
7. 全文確認・抄録確認・電子添文確認・検索先だけの確認を区別して記録する。確認できなかったことを推測で補わない。
8. 本文の引用番号と資料の役割を対応させる。権威あるガイドラインでも、個別食品の安全量を保証する資料として流用しない。

## ガイドラインの位置づけ

- [医薬品開発と適正な情報提供のための薬物相互作用ガイドライン（2018年）](https://www.mhlw.go.jp/web/t_doc?dataId=00tc3525&dataType=1)：開発時の評価と情報提供。2章の吸収・キレートなど、該当する部分を参照。
- [2019年の一部訂正](https://www.mhlw.go.jp/web/t_doc?dataId=00tc3912&dataType=1&pageNo=1)も参照対象とする。
- [薬物相互作用試験に関するガイドライン／ICH M12（2024年11月27日）](https://www.mhlw.go.jp/web/t_doc?dataId=00tc8808&dataType=1&pageNo=1)：重複する代謝・トランスポーター等の評価はこちらを参照。通知は吸収・分布・添付文書等の情報提供について2018年国内ガイドラインの2・3・8章を引き続き参照するよう示す。2018年版を一律に現行全体として扱わない。
- [日本医療薬学会「医療現場における薬物相互作用へのかかわり方ガイド」（2019年）](https://www.jsphcs.jp/wp-content/uploads/2024/10/asc1.pdf)：臨床での評価・マネジメント。Q1、Q5、Q6、Q18等を該当する説明に用いる。現在の全薬剤の注意を網羅するリストとしては扱わない。
