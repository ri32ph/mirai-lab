# 健診の各項目をサイト内で読む

2026年10月27日作成。健診の入口から血糖・脂質・体重・貧血・腎機能・肝機能の6ページへ接続。

各記事は「検査の意味」「相談の目安」「今日できること」「診察時の質問例」「参考資料」で構成。原稿は `topics.json`、表示は `content/adults/checkup-*.html`、共通スタイルは `checkup-guide.css`。

原稿変更後はリポジトリ内で `python3 scripts/build-checkup.py` を実行する。生成したHTMLだけを書き換えない。

## 出典の照合

糖尿病情報センターの検査解説、日本動脈硬化学会のQ&A、日本肥満学会の一般向け解説、国立長寿医療研究センターの貧血解説、日本肝臓学会の奈良宣言、厚生労働省掲載のCKD両立支援手引き、協会けんぽの検査一覧を確認。記事ごとのURLは原稿に記録。

HbA1cは過去1〜2か月の傾向、脂質は項目と採血条件、BMIは肥満と肥満症の違い、貧血は原因の確認、CKDは慢性の持続期間と受診の先延ばしの区別、ALTは30U/L超の受診勧奨と診断の区別を明記。治療目標・再検査時期を一律に決める機能は設けていない。
