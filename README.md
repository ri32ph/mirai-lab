# ミライラボ

薬を知る。健康を考える。自分を大切にする。

共通トップページから、知りたいこと・困りごと・やってみたいことに合わせて各コンテンツへ進む静的サイトです。入口にはラボ名ではなく「何ができるか」を表示します。年齢・対象は利用先を限定する条件ではなく、選ぶための目安です。

## ファイル構成

- `index.html`：共通トップページ
- `style.css`：共通スタイル
- `app.js`：入口データ、テーマ検索、体験サンプル
- `content/children-medicine/`：子どものお薬の使い方・飲ませ方
- `content/kids-youth/`：子ども・若者の薬、体、心の学び
- `content/adults/`：毎日の健康づくり
- `content/older-adults/`：好きなことを続ける工夫
- `content/family/`：子育て、介護、家族の薬

## 確認方法

`index.html` をブラウザで開くだけで利用できます。ビルドや依存パッケージのインストールは不要です。サーバー経由の場合は `python3 -m http.server 8000` を実行します。

## コンテンツを増やすとき

該当する `content/` 配下に記事などのHTMLを追加し、その入口ページの「準備中」を実際の内容へのリンクに置き換えます。記事・クイズ・体験コンテンツを順次追加できます。共通メニューは「知る・考える・やってみる・相談する・ふり返る」を基本とし、対象に応じて調整します。
